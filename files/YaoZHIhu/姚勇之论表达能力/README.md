# 姚勇之论表达能力

本文件夹在 `files/YaoZHIhu/` 下，与《姚勇文章目录》《姚勇奇闻目录%》并列。走口令「收录姚勇文章」，但**文件都放本目录**，序号从本目录独立起算：`01`、`02`、`03`……不占用主文章 1–10 序号。

## 收录规则

以后把表达能力专题的姚勇文章收到这里时：

0. PDF、DOCX、截图都放入本目录（截图放 `截图/`）；不主动读取 `Wushuyao/`。
1. 短标题由 Agent 拟定；文件名为 `01标题.docx`、`02标题.docx`。
2. DOCX 顺序与母口令「收录姚勇文章」相同：文章内容（含原问题、问题描述、正文）→ 评论截图（不转录；按用户要求可不拆分）→ 原文链接。不加 Agent 总结。
3. 源 PDF 保持原截图，不重排。
4. 缺问题标题、问题描述或评论截图时，在对话里提醒，不编造。
5. 更新 `目录.json` 并运行 `更新目录.py`。
