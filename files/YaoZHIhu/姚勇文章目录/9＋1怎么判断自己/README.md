# 9＋1怎么判断自己

和 `2026-9.1自我接纳：四块拆成可勾选项.docx` 同层。

- `01上个问题与回答.docx`：固定保存上一问的问答和链接，少改。
- `01上个问题与回答-持续变动副本.docx`：先与上一份一致，再用不含链接的文字重写一遍，最后是「模板」——你的回答和维度变更写在模板里。
- `发展心理学-单书维度.docx`：只从费尔德曼原书第4版抽出的额外维度，先不并进 1.1.1。
- `判断维度故事库/`：按 1.1.1、1.1.2 分开收典型事件。
- `判断维度工具书/`：公开目录摘录（发展心理学已按PDF页改正）；原著拆分在 `判断维度工具书/发展心理学原著/`。
