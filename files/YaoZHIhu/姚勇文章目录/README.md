# 姚勇文章目录

## 触发口令

以后发送：

> **收录姚勇文章**

并同时提供或上传新文章 PDF/截图、原文链接，即触发以下半自动流程：

0. 将 PDF 放入 `files/YaoZHIhu/`；回答截图放入 `files/YaoZHIhu/AnswerPrintScreen/<文章序号>/`；不主动读取 `Wushuyao/`。
1. 识别文章首次发布时间、后续编辑时间、标题层级、正文、引用和列表；页面无法访问时只使用用户提供的 PDF 或截图。
2. 生成接近原文结构的可编辑 DOCX，排除网页导航、私信数、广告等界面内容；原文链接放在 DOCX 结尾。
   - **问题标题**、**问题描述**写入正文前（楷体「原问题」「问题描述」）。
   - **评论**按知乎界面截图贴在正文后，保留头像以便识别，不另做评论 OCR 转写；截图未展开的评论不补造。
   - 回答页 PDF/截图裁掉右边栏、广告，以及「更多回答」以下他人回答。
3. 若本次缺少问题标题、问题描述或评论截图，必须在对话界面提醒，不编造缺失项。
4. 短标题由 Agent 根据正文拟定；默认按加入顺序命名为 `1标题.docx`、`2标题.docx`，直接放本目录，不另建序号夹。第12篇当时按用户指定放进「序号＋短标题」夹，夹名与 DOCX 全名相同；其余篇不要照推。作者不是姚勇时，文件名写成 `序号[作者另：（知乎名头两个字）]短标题`。更新 `文章目录.json` 并运行 `更新姚勇文章目录.py`。
5. 源 PDF 按原截图归档，不重排成新版面 PDF。文件名为 `年份-短标题.pdf`，放 `files/YaoZHIhu/` 根目录。

分指令（大小写不敏感）：

> **收录姚勇文章 ai总结**

继承上列全部步骤，但 DOCX 顺序改为：**文章内容（含标题、原问题、问题描述、正文）→ Agent 总结 → 评论截图（不转录文字）→ 原文链接**。母口令不加 Agent 总结。

> **收录姚勇文章 ai评论**

与 ai总结并列。DOCX 顺序改为：**文章内容 → Agent 评论 → 评论截图（不转录文字；未见则标明未见）→ 原文链接**。评论不是总结，也不是评价。

> **收录姚勇文章 ai评价**

与 ai总结、ai评论并列。DOCX 顺序改为：**文章内容 → Agent 评价 → 评论截图（不转录文字；未见则标明未见）→ 原文链接**。评价不是总结，也不是评论。默认进本目录；用户写明只进奇闻时改入奇闻目录。

奇闻、科幻想象或趣味性材料使用并列口令 **“收录姚勇奇闻”**，归入 `../姚勇奇闻目录%/`，从独立序号 1 开始。

主文章的局部分支使用 `年份-主序号.小标题序号`，例如第1篇的第8小标题记作 `2022-1.8`。分支DOCX按用户要求不附原文链接，目录也不显示空链接。

表达能力专题另有并列文件夹 `../姚勇之论表达能力/`：走同一口令「收录姚勇文章」，但文件都放该目录，独立序号 `01`、`02`……，不占用主文章序号。

## 对话轮目录

只改目录细节时，默认不刷新 `files/对话轮目录1-Nuwa部署/`（浏览文件 `对话轮目录1-女娲部署之Menu，姚勇.docx`）。用户说「更新目录」才刷新。以后若开新对话，可能另建对话轮目录 2。

## 时间纪律

- 文件序号表示加入顺序，不表示发表先后。
- 首次发布、后续编辑和用户保存快照是三个不同时间。
- 截图只显示到年份或月份时，不擅自补日期。
- 文章发生修改时保留版本说明，避免把新版本观点倒推为早期观点。
