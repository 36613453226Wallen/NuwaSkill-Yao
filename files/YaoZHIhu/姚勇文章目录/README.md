# 姚勇文章目录

## 触发口令

以后发送：

> **收录姚勇文章**

并同时提供或上传新文章 PDF、原文链接，即触发以下半自动流程：

0. 将 PDF 放入 `files/YaoZHIhu/`；不主动读取 `Wushuyao/`。
1. 识别文章首次发布时间、后续编辑时间、标题层级、正文、引用和列表；页面无法访问时只使用用户提供的 PDF。
2. 生成接近原文结构的可编辑 DOCX，排除网页导航、私信数、广告及评论区等界面内容；原文链接放在 DOCX 结尾。
3. 按加入顺序命名为 `1标题.docx`、`2标题.docx`、`3标题.docx`；更新 `文章目录.json` 并运行 `更新姚勇文章目录.py`。

奇闻、科幻想象或趣味性材料使用并列口令 **“收录姚勇奇闻”**，归入 `../姚勇奇闻目录%/`，从独立序号 1 开始。

## 时间纪律

- 文件序号表示加入顺序，不表示发表先后。
- 首次发布、后续编辑和用户保存快照是三个不同时间。
- 截图只显示到年份或月份时，不擅自补日期。
- 文章发生修改时保留版本说明，避免把新版本观点倒推为早期观点。
