# YaoZHIhu 根目录年份文件集

本夹根下以年份开头的 PDF 是一份独立文件集（GitHub 上看到的就是这一层）。夹内 DOCX、奇闻序号夹、截图夹不改这条规则。

## 姚勇

`年份-短标题.pdf`

同一知乎回答的多个收录版本：`主序号-版本-年份-短标题.pdf`（如 `16-1-2026-短标题.pdf`）。

年份用首次发布；截图只有编辑时间、没有发布于时，用最后编辑年份。

## 城市猎人（只改根目录这份）

`年份-[城市猎人]序号短标题.pdf`

- `序号` 是城市猎人自己的单独标号（`城市猎人Z文选` 夹内从 1 起），不是姚勇主文章序号，也不是奇闻总序号。
- 例：`2021-[城市猎人]1看似档次高实则误导：独力可成与需人配合.pdf`
- 夹内仍用 `[作者另：城猎]`，夹内文件名不套这条。
- 年份规则同上。
