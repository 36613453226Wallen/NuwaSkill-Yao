# 姚勇奇闻目录%

## 触发口令

> **收录姚勇奇闻**

使用该口令并提供 PDF 与原文链接后：

1. PDF 归档到 `files/YaoZHIhu/`，不读取 `Wushuyao/`。
2. 从 PDF 识别正文、标题结构、首次发布及后续编辑时间；不访问受限页面补造内容。
3. 根据正文拟定简短标题，生成接近原文结构的可编辑 DOCX。
4. 奇闻类文章单独从序号 1 开始，命名为 `1标题.docx`、`2标题.docx`。
5. 原文链接放在 DOCX 结尾。
6. 更新 `奇闻目录.json` 并运行 `更新姚勇奇闻目录.py`。

该目录与 `姚勇文章目录/` 并列，序号互不影响。
