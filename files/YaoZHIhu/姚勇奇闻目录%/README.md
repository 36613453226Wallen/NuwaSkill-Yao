# 姚勇奇闻目录%

## 触发口令

> **收录姚勇奇闻**

使用该口令并提供 PDF 与原文链接后：

1. 第1–4篇 PDF 归档到 `files/YaoZHIhu/` 根目录；第5篇起源 PDF 放在「序号＋短标题」夹内，**不**进 YaoZHIhu 根目录。不读取 `Wushuyao/`。
2. 从 PDF 识别正文、标题结构、首次发布及后续编辑时间；不访问受限页面补造内容。
3. 根据正文拟定简短标题，生成接近原文结构的可编辑 DOCX。
4. 奇闻类文章单独从序号 1 开始，命名为 `1标题.docx`、`2标题.docx`。第5篇起源文件放在「序号＋短标题」文件夹内。
5. 原文链接放在 DOCX 结尾。
6. 更新 `奇闻目录.json` 并运行 `更新姚勇奇闻目录.py`。
7. 作者不是姚勇时，文件名写成 `序号[作者另：（知乎作者名头两个字）]短标题`（主文章目录同样用这条）。大段评论另建同级文件夹，夹名开头为「【评论】」，夹内 docx 与 pdf 贴同一组评论截图、不转录。
8. 回答页 PDF/截图裁掉右边栏、广告，以及「更多回答」以下他人回答。
9. 只改细节时不自动刷新对话轮目录 1（`files/对话轮目录1-Nuwa部署/`）。用户说「更新目录」才刷新。

该目录与 `姚勇文章目录/` 并列，序号互不影响。
