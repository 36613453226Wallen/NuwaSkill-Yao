# 我的团长'兰利世'

`files/` 下单独夹，用来记团长／导师（兰利世）说过的话。

## 自动记录

对话里出现下列词，或意思很近的说法，就把那一则写入 `团长语录.docx`，不另等口令：

- ee说（最短称呼）
- 团长说
- 姨姨提到过
- 团长讲过
- 导师说过
- 以及「我的团长和导师曾讲过」这类近似句

## 每则格式（两块，不混写）

1. **短回忆与重点可能**：短句，方便回看时抓住重点。
2. **完整语录**：原句尽量不改。若原话有换行，按换行分段，不把两块拼成一段。

可在两块之后另加「Agent 评论」，评论必须有论点、史实论据；涉及正反例时先问：需要限定哪个国家，哪个国家几组正反。
