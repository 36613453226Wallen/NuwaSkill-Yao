# 问题与视角-agent与Y双版本

同一问题保留两份判断：先是普通 Agent 回答，再是姚勇公开框架下的一版。口令总表也放在这里。

## 文件夹里有什么

- 双版本摘录 DOCX：一份文件里用「提问人：」「Agent：」「姚勇视角：」表头摘录。
- `*超级指令.docx`：曾经生成过的关键词口令、提示词文档和自动更新规则。
- `双版本记录.json` / `超级指令.json`：生成 DOCX 的数据源。
- `生成双版本.py`、`更新超级指令.py`、`登记指令.py`：排版与自动更新脚本。

## 口令：AY双问

发送：

> **AY双问**

然后执行：

1. 按姚勇视角再写一版（首次声明：基于公开文章与访谈的模拟，不代表本人）。
2. 把上面的问题与两份回答摘录进**单个** DOCX，要求有表头、用冒号标出发言人，并保持可读排版。
3. 按材料是否齐全分别反馈，同时用一两句说明本文件夹：
   - **没有问题**：不编造提问；说明缺什么；可只刷新口令总表。
   - **只有一份回答**：标明缺 Agent 还是缺姚勇视角；仍可生成带状态说明的文件。
   - **双份回答**：生成完整双版本 DOCX。
4. 若这次同时产生了新的关键词口令或提示词命令，走下面的自动更新。

## 关键词新指令 / 提示词命令

只要新生成了口令或提示词，必须登记进总表，不能只写在聊天里。

```bash
python3 登记指令.py \
  --keyword "新口令" \
  --type "关键词口令" \
  --purpose "一句话用途" \
  --inputs "需要用户提供什么" \
  --operation "逐步做什么" \
  --outputs "生成哪些文件"
```

`登记指令.py` 会按关键词 upsert `超级指令.json`，并立即重写 `*超级指令.docx`。
