# 姚勇 Perspective Skill

基于姚勇公开署名文章、访谈和可核验行业资料提炼的思维顾问 Skill。

## 使用

将本目录复制到 Cursor 的 Skills 目录，或直接保留在兼容 Agent Skills 的运行环境中。

触发示例：

- “用姚勇的视角判断这个 AI 产品值不值得做。”
- “站在姚勇角度，怎么看理想和赚钱的冲突？”
- “继续用刚才的姚勇模式，帮我收窄这个 MVP。”

以下情况不触发：

- “姚勇是哪一年加入水木年华的？”
- “介绍一下姚勇和《QQ 炫舞》的关系。”
- “我该不该创业？”（未明确指定姚勇视角）

## 重要边界

- 姚勇是原**水木年华**成员、王小波的**外甥**。
- 知乎主页 `https://www.zhihu.com/people/H3D` 已通过公开 API 核验姓名和深空交响认证。
- `canglimo`（墨苍离）不是本次调研对象，相关截图与观点没有混入。
- 本 Skill 是公开材料上的框架模拟，不代表姚勇本人。

## 目录

- `SKILL.md`：可运行 Skill。
- `references/research/`：六维调研、身份边界和提炼记录。
- `references/sources/`：已保存的公开材料与来源索引。
- `scripts/`：调研合并和质量检查工具。

## 后续迭代约定

- 用户手动保存的姚勇文章放入 `files/YaoZHIhu/`，文件名以首次发布时间年份开头，例如 `2022-...pdf`。
- `files/YaoZHIhu/Wushuyao/` 是用户个人材料；更新姚勇模型时默认不读取，除非用户明确要求将人物框架应用于个人问题。
- 每次新增文章先记录首次发布时间、快照时间和后续编辑时间，再比较其与现有模型的关系：
  - 强化旧模型：补充证据；
  - 与旧观点冲突：保留早期/近期版本和变化时间；
  - 出现新框架：通过跨域复现、生成力和排他性验证后再加入；
  - 仅是时事判断：进入时间线，不直接升级为稳定人格模型。
